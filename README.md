Documentação do Projeto: Portal de Notícias TecNews
Visão Geral
O Portal de Notícias TecNews é um website responsivo e moderno dedicado à divulgação de notícias e inovações tecnológicas. Desenvolvido com foco em temas emergentes como Inteligência Artificial, Realidade Virtual, Blockchain e Hologramas, o projeto oferece uma experiência de navegação imersiva e intuitiva. Construído exclusivamente com HTML e CSS, ele prioriza acessibilidade, performance e design atrativo, simulando um portal de notícias real com seções dinâmicas e conteúdo visualmente rico.

<h2>
Objetivo do Projeto
</h2>

Divulgar Inovação: Apresentar notícias sobre avanços tecnológicos de forma organizada e envolvente.
Experiência do Usuário: Garantir navegação fluida, com elementos interativos como hover effects e layouts grid-based.
Escalabilidade: Estrutura modular que permite fácil adição de novas seções ou integração com back-end futuro.
Acessibilidade: Uso de semântica HTML, alt texts em imagens e design responsivo para dispositivos móveis.

<h2>
Tecnologias Utilizadas
</h2>

HTML5: Estrutura semântica com elementos como &lt;header>, &lt;nav>, &lt;main>, &lt;section>, &lt;article> e &lt;aside>, garantindo SEO e acessibilidade.
CSS3:
Grid Layout: Para layouts flexíveis e responsivos (ex.: grid-template-areas no main).
Variáveis CSS: Definidas em :root para cores, fontes e tamanhos, facilitando temas e manutenção.
Flexbox: Usado em navegação e cards para alinhamento dinâmico.
Pseudo-elementos: Como ::before para overlays em imagens.
Media Queries: Implícitas via max-width e padding-inline para responsividade.
Google Fonts: Integração com "Archivo" e "Open Sans" para tipografia profissional.
Pré-carregamento: Links preconnect para otimização de carregamento de fontes.
Não há JavaScript ou frameworks; o foco é em CSS puro para interatividade básica (hover).

Navegação Primária:

Links para categorias: Inteligência Artificial, Blockchain, Hologramas, Internet, Vestíveis, Realidade Aumentada, Realidade Virtual.

Card principal com imagem grande e overlay gradiente.
Sub-cards em grid 2x2 com tags de categoria (ex.: "robótica", "hologramas").

Grid de 4 colunas com imagens, tags e resumos.
Links "Ver tudo" com ícones animados no hover.

Artigos em grid vertical com imagem, tag, título e parágrafo.
Conteúdo focado em avanços de IA (previsão, tradução, robôs sociais, produtividade).

Anúncio fixo (imagem de ADS).
Seção "Viu Isso Aqui": Lista de artigos sugeridos com imagens pequenas e títulos.
